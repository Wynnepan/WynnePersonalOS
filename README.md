# 生长台

一个面向成长型内容创作者的双平台个人工作台原型，包含抖音短视频与小红书上班族图文两个内容模式。

## 运行

直接双击 `index.html`，或在目录内运行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 隐私与配置

公开仓库中不保存邮箱、私人文档链接、密码、API Key、Token 或其他凭据。需要接入真实服务时，请把敏感配置放入本地 `.env` 文件；该文件已被 `.gitignore` 排除，禁止提交到 Git。

## 当前能力

- 今日任务的新增、筛选、完成和移除，自动保存在浏览器本地
- 符合“个人成长”定位的爆款灵感列表和换一批
- 每条灵感可生成二创脚本结构与个人化切入角度
- 今日发布数据、AI 优化建议和一键采纳交互
- 桌面端与移动端响应式布局
- 小红书每日对标账号、上班族选题与账号内容配比
- 小红书图文文案生成、标题备选和已发布笔记诊断
- 英语听说读写每日计划、词汇任务与官方公开资料架
- 机器人学习四阶段路线、公开课程与研究方向导航
- 架子鼓每周课程/练习计划、线谱、BPM 和公开教学资源
- 健身训练周计划，以及游泳、普拉提、举铁三项基础知识

## 接入真实数据

当前爆款数据和发布数据为演示数据。正式接入抖音时，建议通过官方开放平台或获得授权的合规数据服务获取账号视频、互动指标与热点素材；前端只需将 `app.js` 中的 `ideas` 和发布数据替换为 API 返回值。
